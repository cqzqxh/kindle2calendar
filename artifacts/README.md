# 日历设计素材

生成提示词及引句来源见各分组内的说明。家庭日历中的日期为日历页日期，不是照片拍摄日期。原照片及衍生图片仅作为仓库内素材保存，不作为公开附件发布。

本地预览、数据 JSON、设备排障照片和重复 ZIP 包继续由 `.gitignore` 排除。
